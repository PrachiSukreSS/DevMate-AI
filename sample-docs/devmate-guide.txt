DevMate helps developers understand a software project and investigate errors. It stores project documentation as text chunks in a local SQLite database. Each chunk contains up to 1,000 characters, with 150 characters shared between neighboring chunks. Keyword search finds chunks that contain words from the question. In mock mode, DevMate returns the matching source excerpts but does not generate an AI answer. A real model can answer from retrieved evidence when OpenAI mode is configured.
